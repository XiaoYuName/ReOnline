Slicer2D Components
Components
Slicer2D
	Physics component for slicing sprites & meshes (Require Collider2D)
	Slicer2DController
	Mainly for mouse input which is used to slice or affect sliceable objects
	Slicer2DParticles
	Adding particles effect for sliceable game object
	Slicer2DSound
	Adding sound effect for sliceable game object
	Slicer2DLinearController
	Simplified version of Slicer2DController for linear mode slicing only
	Slicer2DComplexController
	Simplified version of Slicer2DController for complex mode slicing only
	Bonus Components
Mesh2D
	Creates a mesh from attached Collider2D
	ColliderLineRenderer2D
	Draw lines for the attached Collider2D
	JointRenderer2D
	Draws lines for the attached joint components

AddEvent
	description
	This event is applied before new sliced objects are created.

If this event method
* Returns “false” - the slice will be canceled
* Returns “true” - the slice will be performed


Slice2D object contains fields:
* Polygons
* Slice Type
* Collisions
* Slice
* Slices
	Sample 1
  

Removes smallest slice from result
Smallest new polygon won’t be created
	











	Sample 2
  

This sample canceles the slice if it creates more than 2 new objects
	

	

AddResultEvent
	description
	This event is applied after new sliced objects are created.
This event method cannot cancel slice.

Slice2D object contains fields:
* Game Objects
* Slice Type
* Polygons
* Collisions
* Slice
* Slices


	Sample 1
  

This sample attaches  a rigidbody for every new slice of the object
