# ReDiv 登录界面 UI 拆件

- `logo.png`：游戏 Logo（736×333）
- `language-selector.png`：语言选择（478×167）
- `server-selector.png`：服务器选择（842×218）
- `tap-to-start.png`：点击开始提示（697×323）
- `account-login.png`：账号登录（391×179）
- `announcement.png`：公告按钮（243×248）
- `settings.png`：设置按钮（246×247）
- `version-text.png`：版本文字（274×97）

全部文件为 RGBA PNG，四角透明，并保留了 24px 左右的透明安全边距。完整 2K 平铺图位于上级目录的 `rediv-classic-login-ui-elements-sheet-2k.png`（2048×1152）。

Unity 建议导入设置：`Texture Type = Sprite (2D and UI)`、`Alpha Is Transparency = On`。单独 PNG 可直接使用 `Sprite Mode = Single`；平铺图使用 `Sprite Mode = Multiple`。
